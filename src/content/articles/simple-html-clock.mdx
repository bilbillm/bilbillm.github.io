做了一个很帅的网页时钟。单个 HTML 文件传到 Wallpaper 上应该方便些。

## 初衷

具体的功能 GitHub 仓库里面已经很全了，我在这里更想讲讲自己为什么要做这个网页。

那是大二上（距离本文写作有一段时间）的某一天，**室友 A** 告诉我做了一个很帅的网页时钟。看了他的演示后确实很符合审美，不能说惊世骇俗但也能说出类拔萃。特别是在我知道了成本仅仅只有十几块的 token、一天当中的几个小时，和一个模糊的 idea 的时候，那种羡慕嫉妒的感觉便不自觉地油然而生。

真正让我难以平复的是，过了一段时间后他又找到我，告诉我说有机构愿意出**五位数**的报价购买这个（虽然最后有没有“卖”出去我也不知道）网页。我脑中像闪过一道晴空霹雳，被震傻了。

- 第一想法是：哪个人傻钱多得这么厉害，能花这么多的钱办这么少的事情。
- 第二想法是：我草，不行，我也得做一个（这明明是我也能做到的）。
- 第三想法是：哎，人脉这一块还是室友 A 遥遥领先。

## 完成

嗯，在寒假，把 AI 配置好之后，我的第一件事情就是做一个和他类似的网页。把仓库可见性改为 public 的时候，我有一种自己是户晨风的感觉（lmao）。

肯定不能完美复刻，但是能做到似他三分我便爽了。也不在乎（还是在乎的）他那东西到底能卖多少，反正我做了个类似的并且开源，还发到 Wallpaper 上面去。想用就用，想改就改。

然后发挥国内版权意识淡薄的优良传统：

> 开源 = 创新<br />
> 管你什么狗屁 LICENCE<br />
> 诶我套皮都懒得套，直接复制粘贴一份放到闲鱼淘宝上卖<br />
> 完事了说有问题到 GitHub 仓库那里提 issue，到原作者粉丝群求助<br />
> 完美，售后都不需要自己搞
